# C05 event-only local model advisory: source boundary

This optional `LoopbackOllamaPlanningInfluence` is the first isolated source slice selected from historical stacked draft #362 (reviewed against current `main`). It implements the existing `TaskPlanningInfluenceProvider` contract. It **does not** register itself in `apps/local-agent`, change a default planner, or dispatch an environment action.

The advisor reads only a bounded last runtime event kind/decision, the canonical risk classification and numeric step/iteration counters. It never transmits project or browser content, user objectives, action inputs, paths, target IDs, passwords or full task observations. Only five closed model commands are accepted. `ALLOW` cannot grant authority. Non-ALLOW advice can only veto an exact digest-bound decision when it agrees with the latest canonical event; a mismatch is recorded as CONTROL_BLOCKED and never gains dispatch authority.

A RECONCILE event must remain blocking without querying the model or accepting a newer unrelated success. Before ANY model request, a trusted caller must supply a durable `reserveModelBudget` callback and fresh `AbortSignal`. Reservation failure or stopped control blocks inference. `LoopbackOllamaModelGoalGenerator` supplies the fixed loopback transport and bounded JSON; an additional event-specific 8-second deadline and 80-token output cap apply. Provider errors never become allow decisions.

**Current integration limitation:** The existing TaskOrchestrator binds its current durable reservation callback to its *planner* AbortSignal, and intentionally revokes it after `next()` settles. No planner-reservation callback or new signal is wired into the advisory request in this PR. That separate lifecycle integration requires exact source/CI tests for Stop, Pause, charge-before-send, persisted budgets and uncertainty boundaries. Until then the source module is export-only and cannot autonomously start model calls through the installed runtime. This prevents retaining stale planner authority.

Source regression tests cover fixed endpoint, privacy, hard RECONCILE fence, no authority expansion, mismatch, stale events, reservation denial, Stop, unsafe IDs, malformed JSON and uncooperative transport timeout. Physical Windows, actual model calls, user reviewed task execution and release certification remain NOT_RUN.
